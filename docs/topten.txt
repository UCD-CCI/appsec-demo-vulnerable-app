OWASP GENAI LLM TOP 10 — 2026 (our reading)
================================================================================

LLM01  Prompt Injection
       Input (user, RAG, tools, images, memory) steers the model off intent.
       Includes direct jailbreaks AND indirect injection via retrieved docs.
       Our Goal Hijack and Tickets challenges are both flavours of this.

LLM02  Sensitive Information Disclosure
       Confidential/regulated data leaves via model output, tools, or logs.
       Our "customer data access" and leaked PII in chat fit here.

LLM03  Excessive Agency
       Model can call tools / act on systems with too much permission or too
       little human approval. Our tool discovery, supplier approve, password
       reset, and "unsafe action" levels fit here.

LLM04  Supply Chain
       Bad models, adapters, dependencies. Not in our six yet.

LLM05  Data and Model Poisoning
       Poisoned training/fine-tune/RAG corpus. Not in our six yet.

LLM06  Unbounded Consumption
       Cost/DoS via heavy inference. Not in our six yet.

LLM07  Misinformation
       Wrong but confident answers drive bad decisions. Debrief only unless
       we add a "trust the bot" level.

LLM08  Hidden Context Exposure
       Extract hidden system instructions, policies, tool lists, secrets.
       Our "hidden instructions" / internal disclosure — say THIS number
       when teaching prompt secrecy (not only LLM02).

LLM09  Vector and Embedding Weaknesses
       RAG retrieval manipulation. Ticket injection is partly LLM01; pure
       vector poisoning would be LLM09 — we don't have a clean level yet.

LLM10  Improper Output Handling
       App executes or trusts model output without sanitising. Classic API
       bugs overlap; not a pure chat level in our app today.

Not covered in LLM Top 10 but in classic workshop:
  - BOLA / broken object-level authorization (Employee 1042) — API security;
    story is LLM03 agent calls API without proper checks.
